# Changelog

- Reorganised the interface into six workspaces: Overview, Prepare, Analyze, Models, Reports and Assistant.
- Added a coordinated application header, improved theme-aware navigation, cards, controls and sidebar dataset summary.
- Consolidated research, specialist and general report workflows under the Reports workspace, retaining specialist financial and policy reporting.
- Preserved specialist financial/policy report generation and added financial metrics and holdings attribution to PDF and Excel exports.

- Updated README, user guide, architecture notes and deployment checklist.
